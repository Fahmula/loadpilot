How to use it

Send the token in an Authorization header. To record a broker payment:

curl -X POST {{ request.base_url }}api/payments/ \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"invoice_number": "INV-1001", "amount": 2450}'

The token opens the API only, never these pages. Every endpoint is listed at /docs.
